# 油站设备巡检签收

- 行业：石油
- 技术栈：React、Vite、TypeScript、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

两班巡检员共用同一份设备清单（数据保存在浏览器 localStorage，跨标签页实时同步）。

## 核心规则

- **当天唯一签收**：每台设备每天只能被一个班组签收，签收记录（班组/巡检员/时间/结论/备注）全程留痕，交班可在「交接留痕」中追溯。
- **并发不覆盖**：签收提交时在 localStorage 互斥锁内"重读最新数据再判定"（check-and-set）。两班几乎同时提交时，后到一方会收到冲突提示，看到设备已被对方签收，且不会覆盖对方记录；被拦截的提交也会记入留痕。
- **异常置顶**：上报异常的设备自动置顶到清单最前，并计入顶部异常数；异常未处理前禁止重新签收。
- **处理闭环**：异常必须填写处理说明、完成「处理异常」后才能恢复为正常；处理记录同样留痕。未处理的异常跨天保留，直到被处理。

## 模拟两班并发

开两个浏览器标签页，在页面顶部分别选择「甲班」「乙班」并填写巡检员姓名，然后对同一台设备同时点签收，即可看到后提交一方被拦截。
